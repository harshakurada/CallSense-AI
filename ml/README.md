# ml/

Training code, notebooks, and experiments for Modules 2–17 and 27–28 land here,
one module at a time. See [`docs/module_01_problem_definition_and_architecture.md`](../docs/module_01_problem_definition_and_architecture.md)
for the full pipeline this directory will implement.

- `data/` — dataset download/preprocessing scripts (raw data itself is git-ignored)
- `notebooks/` — exploratory notebooks per module
- `src/` — reusable training/inference source code
